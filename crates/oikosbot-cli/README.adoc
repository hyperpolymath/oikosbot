= `oikosbot-cli`

The `oikosbot` binary is the standalone product surface used by the container
and composite Action. `main.rs` dispatches file/directory analysis, reports,
comparisons and optional-adapter requests; `config.rs` resolves `.oikos.yml`;
`estate.rs` stages and analyzes read-only portfolio telemetry.

See link:../../docs/usage.adoc[usage] for commands, config and the exit contract.
Reports are advisory. Requested blocking checks cannot pass on heuristic evidence:
they return 2 (no check), not 0. Output format does not change enforcement.
Parser/config/traversal errors and unavailable requested integrations are errors,
not silently dropped inputs. Tracing goes to stderr so JSON stdout stays parseable.

`tests/check_gate.rs` provides end-to-end controls for advisory/no-check behavior,
JSON/text output, clean/firing SARIF and taxonomy, exclusions, malformed input,
unsupported config languages and symlinks. These are authored tests, not a proof
that ecological predictions are correct. No current per-file model is calibrated.

----
cargo test --locked -p oikosbot-cli --all-features
----

The optional fleet bridge is not a dependency. Haskell, the App and VeriSimDB
are not implied operational by a successful CLI build.
