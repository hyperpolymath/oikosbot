As of 2026-09-26: *alpha; hold general launch and regulator claims*.
This supersedes earlier descriptions of a “working regulator” based on the
pattern table. Calibration wiring existed, but no calibration receipts were
found; labels alone were not earned evidence.

== Implemented surfaces, not certification

* Standalone Rust analysis, metrics, SARIF, point-vector Pareto comparisons and
  builtin policy adapter. The native Eclexia path reports unavailable.
* Read-only estate telemetry/capability/DEA and snapshot/report commands.
* Previously published Action and container. The pinned digest is an older
  artifact; this branch's changes have not been released into it.
* Haskell independent analyzer and AffineScript App scaffold.

== Proposed hardening on this branch

Heuristic evidence stays Estimated. Invalid comparisons become Indeterminate;
epsilon no longer permits losses/cycles. CLI no-check exits are explicit and
format-independent; parser/traversal/config failures cannot masquerade as success.
Taxonomy is typed and emitted for pattern findings. Collection validates responses,
pagination and partial failures. Candidate container checks and a pinned Rust
version are added. See link:LAUNCH-READINESS.adoc[the full issue-by-issue audit].

The new `pareto::contract` module is an *experimental runtime refinement*, not a
production authority or a proven novel type system. It checks scoped interval
comparisons and non-compensatory hard limits. Its research/proof obligations and
estate relationships are described in
link:research/EVIDENCE-SCOPED-PARETO.adoc[the research note].

== Not demonstrated

Reproducible resource calibration, real workload equivalence, validated physical
budgets, authenticated evidence ingestion, full SARIF schema/Action/release
conformance, mutation/fuzz coverage and benchmark baselines remain outstanding.
The App listener/transport, deployment operations and VeriSimDB runtime client
are not demonstrated. No source-level orchestration claim establishes a deployable App.

Full pinned-toolchain Rust/Haskell/AS/container execution was unavailable.
An older standalone formatter and eight isolated Rust numerical checks ran;
these do not establish workspace integration or serialization correctness.
New tests are authored but require CI execution; earlier successful main-branch
runs do not test this branch. Check `STATE.a2ml [launch-hardening-audit]` for exact
local verification. No release-readiness grade or formal proof is claimed.
