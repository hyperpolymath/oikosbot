= OikosBot Quickstart
:icons: font

*Alpha, advisory use only.* See link:docs/LAUNCH-READINESS.adoc[the launch hold]
and link:CONTRIBUTING.adoc[toolchain/native build prerequisites].

[source,bash]
----
cargo build --release --locked -p oikosbot-cli
./target/release/oikosbot analyze path/to/file.rs --format json
./target/release/oikosbot report path/to/repo --format sarif --output results.sarif
./target/release/oikosbot compare path/to/base path/to/head --format json
----

Supported source languages are Rust (`.rs`), JavaScript (`.js`) and Python (`.py`).
A directory scan must find analyzable functions; unsupported, empty or fully
excluded input is not a successful scan. Configure mode/excludes/languages with
`.oikos.yml` or `--config`; see link:docs/usage.adoc[the user guide].

Numbers are *heuristic estimates*, including recognized pattern-table rows.
No calibration receipt currently validates those rows or their envelopes.
`compare --check` and blocking `check` therefore return *2 (no check performed)*
when evidence is insufficient. Use `report` or plain `compare` for advisory use.
A documented trade-off cannot turn an estimate into evidence or approval.

Pareto comparisons report improvement, regression, trade-off, neutral or
indeterminate within the declared numeric model. They do not establish ecological
benefit for equivalent real workloads. Scores are heuristic and weights encode
value choices; do not optimize for the score instead of useful work.

[source,bash]
----
cargo test --workspace --locked
cargo fmt --check
bash tests/test-eclexia-adapter.sh
----

The builtin Eclexia adapter does not execute arbitrary `.ecl`; native integration
is explicitly unavailable. The self-analysis command is a demonstration, *not*
a benchmark or proof that OikosBot itself is resource-efficient.
